TinyLife 0.5
============

Это большая рабочая версия проекта.

Структура:
- index.html
- style.css
- assets.css
- game.js
- README.txt
- assets/

Главные системы:
- реальный календарь с корректным количеством дней в месяце;
- день недели автоматически вычисляется по дате;
- часы и периоды суток;
- энергия, голод, настроение, гигиена;
- школа и репутация;
- деньги и работа;
- быстрые действия;
- кликабельные предметы комнаты;
- движение персонажа между объектами;
- редактор персонажа;
- три готовых образа;
- четыре состояния выражения;
- инвентарь;
- расписание;
- журнал событий;
- сохранение и загрузка через localStorage;
- автоматическое сохранение;
- сброс игры;
- адаптация под iPad;
- клавиатурная доступность.

Важно:
Предметы в комнате НЕ являются обычными кнопками нижней панели.
Они сделаны отдельными интерактивными объектами сцены.

Для GitHub Pages:
1. Загрузите содержимое этой папки в репозиторий.
2. Сохраните index.html в корне.
3. Убедитесь, что папка assets находится рядом с index.html.
4. В GitHub Pages выберите Deploy from branch -> main -> /(root).

Текущие изображения персонажей используются как готовые образы.
Настоящая система независимых слоёв одежды/волос может быть добавлена
поверх этой архитектуры без переписывания системы сохранений и времени.
